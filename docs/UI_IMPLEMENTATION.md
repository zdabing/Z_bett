# LuCI UI 实现与设备验收（2026-10-25）

九页：概览、代理、连接、订阅、脚本、资源、工具箱、日志、设置。复用 `bettbox/ui.js` 与应用范围内的 `bettbox/ui.css`，没有修改 Zen 主题项目。手机外层 12px，PC 24px；手机九个主导航两行常显。继承主题字体及浅色/深色配色。

## 实现

- 概览：服务/模式、上下行即时速率、活动连接、进程 RSS、累计上传与下载环形统计、LAN IP、直连和代理出口、六站连通性。速率来自相邻 `/connections` 快照的真实时间差；累计值重启核心归零。没有把内网未经过核心的 NAS 流量计入其中。
- 代理：V4 可折叠策略组、搜索/排序、卡片/列表、当前出口链、切换节点、单节点/本组/全部检测。名称按钮执行选择，独立延迟按钮仅检测；子策略组解析到当前出口，失败/超时可单独重试，未测不显示 0ms。组、当前出口与节点保留订阅图标。
- 连接：PC 表格、手机卡片、搜索、协议筛选、排序、分页、暂停、详情及关闭。实时刷新失败保留旧列表并显示错误。
- 订阅：当前订阅、更新、用量/到期信息、添加/编辑/删除、JS 覆写和规则覆写。操作结果经 RPC 校验。
- 脚本：文件列表、代码编辑、新建、URL/本地导入、保存/删除、默认选项预览。实际覆写开关在订阅中保存。
- 资源：实际 Geo 文件大小/更新时间/安装状态、核心统一 Geo 更新、控制面板安装入口、本地备份下载与上传恢复。未实现核心不存在的“单文件更新”。
- 工具箱：原有十项工具保留，按选中项展示输入和结果。耗时诊断改为有并发数/时间/输出上限的私有后台任务，页面通过 RPC 查询结果，不占住 rpcd 等待网络结束。
- 日志：核心实际 level 优先，syslog 回退，关键字、级别筛选、暂停、导出。正文中的 error 不等于 error 级别。
- 设置：类别导航、手机堆叠表单、固定保存栏，仅写入变化项，提交并真实应用配置，失败明确提示。

直连出口在 TUN Fake-IP 模式下，先从核心 DNS 查询 API 取得真实 A 记录，再将查询连接绑定实际 WAN。避免把 Fake-IP 送到物理出口而超时。公网 IP 地区信息来自查询服务，可能与实际城市有误差。

- HTTPS 访问经 LuCI RPC 转发核心请求，`/connections` 正常返回，未触发混合内容错误。
- 22 项核心/RPC 回归、10 项日志级别用例、24 项 shell 回归、8 项 cron、4 项路由设置测试及渲染/TUN 栈往返测试通过；新 shell 和 ucode 在设备上完成语法编译及运行校验。

## 2026-10-26：V4 代理页正式实现

正式 `view/bettbox/proxies.js` 已替换为确认的 V4：PC 两列策略组、手机单列组与双列节点；默认展开前两组，其余组的当前出口仍可见。按订阅保存展开状态，支持全部展开/收起、组/节点搜索、默认/延迟/名称排序和卡片/列表切换。按 GLOBAL 顺序列出组，追加未列入 GLOBAL 的可见组，隐藏组仍可作为组成员。

节点名称选择与独立延迟检测分开，右键可测试；选择经真实 `Core.put` 确认后更新标记，并处理读取旧快照与选择写入之间的竞争。单测、本组和全部检测共享最多两路的异步诊断队列，按实际出口和测试 URL 去重；排队、检测、成功、超时、失败均单独显示。子组解析有循环保护，REJECT/PASS 不发起测试。测试地址可修改；后台目前固定 4000ms，未提供没有后端支持的 8s/10s 选项。

控制器异常使用紧凑错误条，区分认证失败/连接超时/其他中断；保留本页已读取的快照，禁用测试与选择，支持重试。初次不可达、无策略组和无搜索结果分别显示，不将旧数据写入跨页面持久缓存。共享 CSS 加版本参数避免旧缓存。
